# AIKAGAN Web

Public web platform for **AIKAGAN / AutonomaX** — practical AI business tools, guided execution, implementation services, and a free-first network for founders, operators, creators, and small teams.

## Try it live

- **Free tools:** https://aikagan.com/tools/?utm_source=github&utm_medium=repository&utm_campaign=aikagan_network
- **Revenue Leak Scan:** https://aikagan.com/tools/revenue-leak-scan/?utm_source=github&utm_medium=repository&utm_campaign=aikagan_network
- **AIKAGAN Network:** https://aikagan.com/network/?utm_source=github&utm_medium=repository&utm_campaign=aikagan_network
- **AutonomaX Explorer:** https://app.aikagan.com/autonomax/
- **Builder feedback thread:** https://github.com/laziestlarry/aikagan-web/issues/38

The public model is intentionally simple: **try something useful before you buy anything**.

Visitors can diagnose revenue friction, inspect a practical delivery sample, explore AutonomaX, submit feedback, join the network, or move into DIY products and implementation only after they understand the value.

## Current growth loop

`visitor → free value → useful result → network/share → attributed visit → feedback → better tool → optional paid implementation or verified referral sale`

## External publishing readiness

The production site includes canonical URLs, Open Graph/Twitter metadata, `robots.txt`, `sitemap.xml`, `llms.txt`, GA4/GTM measurement, UTM-tagged share links, and server-side Meta CAPI lead attribution when configured.

Public builder discussion and issue reporting are available in GitHub issue #38.

## Development

```bash
npm install
npm run dev
npm run build
```

Primary stack: **Next.js 15**, **React**, **TypeScript**, **Tailwind CSS**, and Vercel production deployment.

## Repository note

This repository is the production web application. Commercial claims should remain evidence-based: page access is not proof of payment, and referral commission is attributed only to verified paid orders.
